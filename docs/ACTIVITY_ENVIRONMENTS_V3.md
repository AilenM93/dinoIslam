# Escenarios de actividades V3

Cada zona abre un entorno cercano propio, con Minti y el compañero de esa zona. Las cuatro actividades de una misma zona comparten entorno; cada una conserva sus preguntas y mecánica. Los fondos se cargan al entrar por primera vez y se reutilizan durante la sesión. Se conserva la progresión existente.

Se generaron cinco fondos con la herramienta integrada image_gen. Referencia de estilo: `public/assets/island-adventure-map-v2.png`. Los personajes se componen en Phaser, no están pintados en los fondos. La interfaz deja ver el entorno entre la pregunta, las tarjetas y la ayuda, y ofrece regreso al mapa durante la actividad.
